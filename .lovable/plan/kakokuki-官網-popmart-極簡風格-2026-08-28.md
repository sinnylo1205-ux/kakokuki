# KAKOKUKI 官網（POPMART 極簡風格）

## 目標
以 POPMART HK 的極簡、大量留白、方形圖卡網格風格，建立 KAKOKUKI 官網首頁與 7 個商品訂購頁，全站繁體中文。

## 首頁結構（無 navbar）
```text
[ HERO 全寬橫幅圖 ]

H1  主打系列 — 聖誕跳跳做什麼

第一列（裸裝情境）  7 張方形圖卡網格
  烤雞 / 禮物 / 聖誕樹 / 可可 / 卡片 / 麋鹿髮箍 / 六入大合照

第二列（盒裝）  7 張方形圖卡網格
  （圖片待補，先以同構版位＋淡色佔位框呈現）

[ FOOTER ]
```
- 圖卡：無邊框、極細灰線分隔、hover 圖片微幅縮放、下方僅商品名 + 價格（POPMART 式極簡）。
- 桌機 4 欄 / 平板 3 欄 / 手機 2 欄。

## 商品訂購頁（7 頁）
路由：`/product/$slug`
- 左：主圖，滑鼠移入啟動「放大鏡」效果 — 游標處顯示放大鏡圓形鏡片，內部以 2.5x 放大原圖並跟隨游標（手機退化為點擊全螢幕檢視）。
- 右：商品名、價格、數量加減（1–99）、小計、「加入購物袋」按鈕（僅前端提示，不接金流）、商品說明與規格。
- 價格：單入 NT$210、六入 NT$1,320。
- 底部：其他商品推薦列。

## Footer
極簡黑底、三欄連結：
- 客戶服務：常見問題、隱私權政策、退換貨說明、聯絡我們
- 關於：品牌故事
- 追蹤我們：Instagram、Facebook、LINE（連結先留 `#`，之後補上）
- 底部：KAKOKUKI logo + © 版權

同步建立 `/faq`、`/privacy` 兩個簡版靜態頁，讓 footer 連結可用。

## 設計方向
- 色彩：紙白底 + 近黑文字，聖誕紅與聖誕綠作為極少量點綴（沿用商品照色調）。
- 字體：無襯線、標題極粗（呼應 KAKOKUKI logo 的粗黑字），字距收緊。
- 動效克制：僅圖卡 hover 縮放與淡入。

## 技術細節
- 商品資料集中於 `src/data/products.ts`（slug、名稱、價格、圖片、說明、單入/六入）。
- 上傳的 hero、logo、6 張情境圖、六入合照透過 Lovable Assets 建立 CDN pointer 後引用，不把二進位檔放進 repo。
- 放大鏡以自訂 `ImageMagnifier` 元件實作（滑鼠座標 + background-position），無新依賴。
- 數量狀態純 `useState`，不使用後端。
- 每個路由各自 `head()`：標題／描述／og。
